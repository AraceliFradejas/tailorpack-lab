# Guion de demostración — 90 segundos

Material preparado para una grabación; no se incluye un vídeo grabado.

1. **0–15 s · Problema.** Mostrar la galería del README. «Empaquetamos cuadrados
   unitarios sin solapamientos en el menor contenedor cuadrado.»
2. **15–30 s · Control y resultado.** Mostrar n=5 y n=10. Explicar que n=5 es una
   construcción explícita y que la búsqueda aporta la mejora de n=10.
3. **30–45 s · Experimento honesto.** Abrir la tabla de diez semillas: 3/10 éxitos,
   mediana 4. Mencionar la campaña inicial sin mejoras.
4. **45–60 s · Ingeniería.** Mostrar el gráfico de pares y rendimiento; explicar
   checkpoint y recuperación con el mismo comando. Aclarar la carga medida.
5. **60–75 s · Evidencia.** Abrir el informe final: hash del CSV, veinte puzzles,
   razones de aceptación y score offline. Distinguirlo de un envío a Kaggle.
6. **75–90 s · Reproducibilidad y siguiente paso.** Mostrar los dos comandos del
   README. Cerrar con movimientos colectivos y más inicializaciones como trabajo
   pendiente para mejorar calidad.
